04 / THỰC HÀNH KỸ THUẬT

Công cụ đang sử dụng.

C và AVR cho phần cứng; Python và PyTorch cho học máy; Unity và C# cho mô phỏng.

01

Hệ thống & phần mềm

C++ hiện đại (template, tính toán tại thời điểm biên dịch); C gần phần cứng với vi điều khiển AVR, thanh ghi, bộ định thời và chương trình phục vụ ngắt cho ma trận LED; Java; HTML, CSS, JavaScript và React.

02

Học máy & dữ liệu

Python và PyTorch cho pipeline học máy, gồm mô hình ngôn ngữ mức ký tự và trích xuất dữ liệu lâm sàng; triển khai Qwen và DeepSeek cục bộ; các khóa học DeepLearning.AI trên Coursera.

03

Mô phỏng & quy trình

Unity và C# cho mô phỏng 3D, dữ liệu OpenStreetMap để tạo mô hình thành phố, cùng Git và LaTeX.
